## Zotero 插件：从「会话级右侧栏 tab」改造为「系统级常驻右栏」

**诉求**：面板要与会话右侧面板同级、常驻右侧、不随会话变动、系统级唯一实例、可收起且收起状态持久。

**根因（查实）**：旧实现把正文注册在 `sidebar.right.pane.tab` —— `sidebar.right.*` 的 6 个席位**全部是 `scope:'session'`**，展开态与标签按 `dsh.sidebar-right.v1.<sessionId>` 持久；`ctx.sidebarRight` 的所有命令都要求「当前有会话上屏」。框架**根本没有** pin/常驻功能（旧代码里的「常驻」按钮是自己实现的逐会话 `openTab` 重试）。

**框架硬约束（重要，后续别再摸索）**：
- `AppFrame` 网格只有 3 条轨道 `sidebar | center | rightbar`（`ui-layout/lib/client.js:320`），**没有第二条右栏轨道**。
- `rightbar` 是 single/root 且已被 `ui-sidebar-right` 占用；再注册是 **shadow 顶掉**，不是并排。
- 根作用域容器级席位只有 6 个：`root`、`sidebar`、`main`(keyed)、`rightbar`、`shell.overlay`(list)、`shell.leading`。
- `shell.overlay` 是唯一「可叠加的插件自有全 frame 浮层」席位；CSS `absolute; inset:0; z-index:20; pointer-events:none`，其直接子元素自动 `pointer-events:auto`。
- `inputActions`（精确光标处插入）是 `uiSession.provide` 下发的**会话作用域标准 prop**，root 作用域按 `ScopeStandardProps` 规则拿不到。降级通道：`mounted` sessionId → `ctx.sessions.scope(id)` → `ctx.conversation.input.for(actx)` → `SessionInput`（有 `state`/`setDraft`/`submit`，**没有** `captureInsertion`/`insertText`）。
- 右栏几何只能在运行时从 DOM 读：frame 内联 `gridTemplateColumns` 第三轨 / `div.frame[data-rightbar-fullscreen]` / `[data-shell-overlay]`（反查 frame）。

**实施（已完成，typecheck + build 通过）**：
- 新增 `src/client/railPrefs.ts`（localStorage 键 `dsh-plugin-zotero.rail.v1` 存 `{open,width}`）、`railGeometry.ts`（ResizeObserver + MutationObserver 观测 frame 的 style/fullscreen 属性）、`ZoteroRail.tsx`（浮层外壳 + 收起把手 + 左边缘拖拽改宽）。
- 改 `index.ts`：删掉 `sidebarRightTabs.register` / `sidebar.right.pane.tab` 注册 / `registerCloseHandler` / `ResidentWatcher` 哨兵；改为 `ctx.slots.inject('shell.overlay', ...)` 注册常驻栏；`inject` 增加 `sessions`、`conversation`（服务名已核实：`ISessions` 在 `dsh-api-session-controller`，`IConversation` 在 `dsh-client-ui-conversation`）。插入走 `createDraftTarget`（**追加到草稿末尾**的降级语义）。
- 改 `ZoteroPane.tsx`（`inputActions` → `InsertTarget`；常驻开关 → 收起按钮）、`inline.ts`（抽出 `InsertTarget` + `createInputTarget` / `createDraftTarget`）、`locales.ts`、`dsh-client.d.ts`（补两个 Chevron 图标声明）、`package.json`（client.inject 加 `dsh-client-ui-layout`）。
- **删除** `src/client/resident.ts`。
- 同步更新 `docs/插件使用说明/dsh-plugin-zotero使用说明.zh.md`。

**已知代价（需在真机验证）**：浮层不占轨道 → 盖住中栏右缘；插入语义从「光标处」降为「追加到末尾」。方案文件：`/Users/peijiping/.workbuddy/plans/electric-forging-babbage-2wo6aEH7.md`。

## 追加：浮层方案被否决，已全量回退 + 移除「常驻」

**用户实测反馈**：浮层式常驻右栏**效果不好**；且「常驻」按钮的实际用户体验也不好 → 要求把面板改回会话级右侧面板内的 tab，并彻底去掉常驻。

**关键教训：不能用 `git checkout HEAD` 回退。** HEAD（`9bee608`）不是改造前的工作区状态：
- HEAD 的 `src/client/ZoteroPane.tsx` 是 **319 行**，改造前工作区是 **259 行**（工作区有一份未提交的重构）；
- `paneStore.ts` / `resident.ts` 不在 HEAD 中（未跟踪）；
- 使用说明文档在改造前就有未提交改动。
正确做法：按「本次会话读到的改造前内容」逐文件精确恢复。回退后 `package.json`、`dsh-client.d.ts`、`inline.ts`、`locales.ts` 与 HEAD **完全一致**（可作交叉校验）。

**回退内容**：
- `index.ts` → 回到 `sidebarRightTabs.register` + `sidebar.right.pane.tab` + `guide`，`inject = ['slots','locale','sidebarRightTabs']`；删掉 `shell.overlay` 注册、`sessions`/`conversation` 服务声明与 `createDraftTarget`。
- `inline.ts` → 恢复 37 行原版（`InputActions` + `insertBuilt`），删掉 `InsertTarget`/两条适配器。
- `ZoteroPane.tsx` → 恢复 `inputActions`（光标处插入），头部只留「刷新」。

- **删除** `ZoteroRail.tsx` / `railGeometry.ts` / `railPrefs.ts`；`resident.ts` 保持删除。**框架席位体系等调研结论已沉淀到 `MEMORY.md`**，将来若想再试可据此重建。
