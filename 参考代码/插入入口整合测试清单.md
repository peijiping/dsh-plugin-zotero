**优先级说明**

- **P0**：核心链路阻断项，任一失败即判本次改动不通过。
- **P1**：重要功能或明显体验问题，需有结论（修复或记录为可接受差异）。
- **P2**：边界、主题、兼容性观察项，可记录后延后。

**结果填写**：每项 `- [ ]` 打勾表示通过；失败写 `FAIL` 并附缺陷编号（见第 7 节）。不能执行的写 `N/A` 并说明原因，**不要直接判失败**。

**给执行者的建议**：先用第 4 节那几条 Console 断言做结构筛查（30 秒能定 A-01 / B-01 / D-01 三个结构项），再按 A → I 顺序逐项验；E 组的兜底与截断依赖特定样本，拿不到就标 `N/A`，别硬凑。

**三个刻意的设计取舍，不要当 bug 报**

1. 下拉第一项「插入文献信息」与左侧主按钮是同一个动作，重复是有意的（主按钮上只有「加入对话」四个字，说不清插的是什么）。
2. 「整篇全文」点下去直接插入，**没有二次确认、没有撤销**。字数已经写在菜单项右侧。
3. 独立笔记（条目类型 = 笔记）的菜单里**没有**整篇 / 章节 / 区间三项——笔记没有全文索引也没有章节，摆一排灰的没意义；但截图还在。

用 `dsh web` 在本机浏览器测（与上一份《PDF阅读器重构测试清单》同一套流程）：

```bash
pnpm build:client

dsh web --port 8090 --no-open
```

访问 `http://127.0.0.1:8090`。若沿用本地 profile，端口也可能是 `3090`（demo）或 `55113`（desktop），以实际为准。

> 若 Zotero 未运行：A、B 两组（纯前端结构与交互）仍可测；C/D/E/F/G 标记 **BLOCKED**。

### 1.2 测试样本

在 Zotero 里准备下面这几条。缺的标 `N/A`，但 **S1–S5 必须齐**，否则 E 组测不完整。

| 编号 | 样本 | 怎么来 | 用途 |
|---|---|---|---|

## 3. 详细测试项

### A. 顶部按钮行

- [ ] **A-01（P0）三个按钮收成一枚**
  - 步骤：打开 S1 条目详情，看阅读区左上角那一行。
  - 预期：从左到右只有「目录图标、`i`、一枚分裂按钮」。分裂按钮左半是文字「加入对话」，右半是一条竖线 + 向下箭头。页面上**不存在**独立的「全文」「截图加入对话」文字按钮。
  - 断言（Console，**先把菜单收起再跑**，否则菜单项本身也是 button）：
    ```js
    [...document.querySelectorAll('button')]
      .filter(b => b.getAttribute('role') !== 'menuitem')
      .map(b => b.textContent.trim())
      .filter(t => t === '全文' || t === '截图加入对话')   // 应为 []
    ```

- [ ] **A-02（P1）标题让出空间**
  - 步骤：打开同一篇文档，检查根节点上的 CSS 变量。
  - 断言：`document.querySelector('[style*="--dsh-zp-topbar-pad"]').style.getPropertyValue('--dsh-zp-topbar-pad')` 的值应在 **120–180px** 之间（改造前约 224px）。
  - 预期：工具条标题左侧留白明显变窄，同一条文献标题能多显示 5–8 个字，仍然居中、不换行、超长时有省略号。

- [ ] **A-03（P0）主按钮 1 击插文献信息**
  - 步骤：点分裂按钮左半「加入对话」。
  - 预期：输入框出现一枚条目胶囊（`item:` 引用，标签是文献标题），**没有**任何弹层出现；出现 toast「已添加到会话草稿」。

- [ ] **A-04（P0）箭头展开菜单**
  - 步骤：点分裂按钮右半箭头。
  - 预期：菜单出现在按钮**正下方**（间距约 4px），左边缘与按钮左边缘对齐；不遮住按钮本身；箭头 `aria-expanded` 变 `true`。
  - 断言：`!!document.querySelector('[role="menu"][aria-label="更多插入方式"]')` 为 `true`。

- [ ] **A-05（P0）再点箭头收起**
  - 步骤：菜单打开状态下再点一次箭头。
  - 预期：菜单消失，`aria-expanded` 变 `false`。

- [ ] **A-06（P0）点外部收起**
  - 步骤：菜单打开时点正文任意位置 / 点下方聊天输入框。
  - 预期：菜单收起；点到哪儿不影响哪儿（聊天输入框正常获得焦点）。

- [ ] **A-07（P1）Esc 收起**
  - 步骤：菜单打开时按 `Esc`。
  - 预期：菜单收起；不会退出文档、不会关闭面板。

- [ ] **A-08（P1）菜单开着时点主按钮**
  - 步骤：展开菜单，然后点左半「加入对话」。
  - 预期：插入文献信息 **且** 菜单同时收起，不会留下一个挡在正文上的下拉。

- [ ] **A-09（P2，桌面端专测）拖菜单不该拖窗口**
  - 步骤：在 DSH 桌面端，按住菜单空白处（不要按在菜单项文字上）拖动。
  - 预期：菜单和窗口都**不动**；绝不能出现「整个 DSH 窗口被拖走」。
  - 说明：这条只能桌面端验，浏览器里标 `N/A`。

### B. 菜单结构与交互

- [ ] **B-01（P0）五项、顺序与分组正确**

- [ ] **B-09（P2）首帧章节数是异步的**
  - 步骤：新开一篇文档，**立刻**点箭头看菜单；等 3–5 秒后再看一次。
